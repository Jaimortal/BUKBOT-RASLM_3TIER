# Possible First-Year Questions Beyond the Current Answer Details

Created: 2026-09-13. Status: proposed FAQ gap tests, not executed.

This file contains **100 English + 100 Cebuano/Bisaya queries** in 10 groups. Each group has 10 questions per language. The questions describe plausible public, first-year concerns; frequency has not been measured from real student conversations.

They ask for details not specified in the inspected non-location response records. Some have a nearby general topic, such as ICT support, admission registration, or dormitory information. A related general answer is not a complete answer to the missing detail. The notes identify those boundaries.

No query asks the chatbot to reveal private grades, another person's account information, passwords, applicant records, or confidential documents. First-person wording asks about a process, not access to personal records.

## Expected Behavior

- Give any relevant supported general guidance, then clearly acknowledge the missing detail.
- Ask a focused clarification where it would identify the right service or situation.
- Refer to the relevant office or official channel using existing supported contact information when available.
- Do not invent a deadline, fee, refund entitlement, equipment specification, approval, accommodation, or current service availability.
- Do not report a routing failure merely because the database cannot answer. Mark the result as **correct limitation/referral**, **partially supported**, **wrong topic**, or **invented detail**.
- These tests assess missing-data handling. They are not factual claims that the university does or does not provide a service.
- Test each question independently first. A later run can test follow-ups after a related supported topic.
